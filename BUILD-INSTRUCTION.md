# Build Instruction

This project is a Next.js foundation for Kang Hendar's Personal Digital Business Card / Personal Landing Card.

## Requirements

- Node.js 24 or newer is recommended for this workspace.
- npm is used as the package manager.

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

The app runs locally through the Next.js development server.

## Production Build

```bash
npm run build
```

## Start Production Server

```bash
npm run start
```

## Current Stack

- Next.js App Router.
- TypeScript.
- Tailwind CSS.
- shadcn/ui component system.
- Geist typography.

## Build Scope

- The intended output is a static one-page personal landing card.
- The site should prioritize identity, positioning, project credibility, and contact paths.
- No backend, database, CMS, authentication, dashboard, blog, or PWA setup should be added.
- UI implementation should follow `CONTENT-STRUCTURE.md` and `DESIGN-SYSTEM.md`.

## Command Rule

When running commands in this workspace, follow `AGENTS.md`: prefix shell commands with `rtk`.
